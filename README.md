# 🚀 C# Learning Roadmap

Repository ini berisi dokumentasi perjalanan belajar C# dari dasar hingga Object-Oriented Programming (OOP) lanjutan, lengkap dengan latihan, eksperimen kode, dan implementasi konsep-konsep penting dalam pengembangan aplikasi menggunakan .NET.

## 📚 1. Data Type and Operator

Memahami fondasi bahasa C# dan pengolahan data dasar.

* Introduction to Variable
* Operator and Parse
* String Manipulation
* DateTime Manipulation
* Decimal Formatting
* Nullable Data Type

### Skills

✔ Variables & Data Types
✔ Type Conversion
✔ String Processing
✔ Date & Time Handling
✔ Numeric Formatting
✔ Null Handling

---

## 🔀 2. Logical Statement

Mempelajari pengambilan keputusan dan alur program.

* Selection Statement (if, else, switch)
* Iteration Statement (for, while, do-while, foreach)
* Jump Statement (break, continue, return)
* Exception Handling (try-catch-finally)
* Checked & Unchecked

### Skills

✔ Conditional Logic
✔ Looping
✔ Error Handling
✔ Flow Control

---

Mengenal struktur data bawaan .NET untuk mengelola data secara efisien.

* Array

* SortedList
* Hashtable
* Stack Collection
* Queue Collection

### Skills

✔ Data Storage
✔ Collection Management

✔ LIFO & FIFO Concepts

## 🎯 Learning Outcome

Setelah menyelesaikan seluruh modul ini, saya mampu:

* Menulis program C# dari dasar hingga tingkat menengah.
* Memahami konsep procedural programming dan OOP.
* Menggunakan collection framework pada .NET.
* Menerapkan encapsulation, inheritance, abstraction, dan polymorphism.
* Mengelola error handling dengan baik.
* Mengembangkan fondasi yang kuat untuk membangun aplikasi desktop, web, maupun backend menggunakan C# dan .NET.
